# RoboSpider
### A Quadruped Search-and-Rescue Prototype
ResQBot is my final year project for the Bachelor of Engineering (Honours) in Software and Electronic Engineering at Atlantic Technological University (ATU).

The aim is to develop a small quadruped robot that can explore confined spaces in a simulated disaster environment, such as an area affected by an earthquake. The robot will provide live visual information and help an operator identify possible signs of life in places that are difficult to access.

## Project Status
**In development — research and planning stage.**

Current work focuses on researching A* pathfinding and audio-based person detection, and planning how these features could be integrated with the robot. The features below are planned and have not yet all been implemented or tested.

## Planned Features
- **Manual control:** Allow an operator to control the robot remotely.
- **Live video:** Stream footage from the onboard camera to the operator.
- **Camera-based person detection:** Identify possible people in the camera feed.
- **Audio detection:** Investigate detecting human speech or calls for help.
- **Obstacle sensing:** Detect nearby obstacles to support safer movement.
- **Mapping and pathfinding:** Explore a simple map overlay and A* path planning.

## Hardware
The planned platform is the **Adeept DarkPaw Quadruped Spider Robot Kit**, using a **Raspberry Pi** for processing and control.

Additional hardware will include a camera, obstacle sensors and a microphone for audio detection. Exact components will be confirmed as development progresses.

## Software
**Python** is the planned main programming language. Software development will focus on robot control, video streaming, sensor processing, person detection and pathfinding.

The DarkPaw kit provides the base platform. My work will focus on developing and integrating the search-and-rescue functionality, with any reused libraries or kit software documented as they are added.

## Development Plan
1. Research the robot platform, sensors and detection methods.
2. Build and test a simple A* pathfinding simulation.
3. Assemble the robot and establish basic movement and manual control.
4. Add the camera feed and obstacle sensing.
5. Develop and evaluate camera and audio detection features.
6. Integrate the system and test it in a controlled simulated environment.

## Setup and Usage
Installation instructions, dependencies and run commands will be added once the initial software is available.

## Project Scope
ResQBot is an academic prototype intended for controlled demonstrations and testing. It is not intended for deployment in real disaster situations.
